# 🚢 Titanic Survival Prediction

## 📌 Problem Statement
Understand factors that influenced passenger survival during the Titanic disaster.

## 🎯 Objective
Perform EDA and build a classification model to predict survival.

## 📂 Dataset
- Source: Kaggle Titanic Dataset

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Seaborn, Matplotlib
- Scikit-learn

## 🔍 Methodology
- Cleaned missing values
- Performed EDA on age, gender, class
- Built Logistic Regression model

## 📊 Key Findings
- Higher survival among females
- First-class passengers had higher survival rates

## ✅ Conclusion
Socio-economic factors played a major role in survival outcomes.
